## 下单前要弄清楚的几个限制

**控制面板是 ctrl，不是老教程里的 SolusVM。** 网上很多教程还在写 SolusVM，那是旧信息。官方现在配的是自研的 ctrl 面板，能做的事包括重启和开关机、重装操作系统、打开带外 HTML5 VNC 控制台、设置入站防火墙规则、一键安装应用、重置 root 密码、发起套餐升级。官方页面上还有一个不需要注册就能点的交互式 demo，下单前可以先去点一遍看顺不顺手。

**这是非托管 VPS。** 官方 FAQ 明确写了 unmanaged。ctrl 负责的是电源、重装、控制台、一键应用、防火墙这些平台层操作，系统里的环境配置、安全加固、数据备份都得你自己来。没接触过 Linux 的话，这批套餐不是入门选择。

**退款默认不给。** 这一点值得单独提醒，因为不少导购文写着"3 天内未使用可全额退款"。官方服务条款的原话是按个案处理，付款后默认不提供退款，理由是会实际产生开通成本；官方知识库里也明确写了不提供退款和退款保证。真有特殊情况可以开工单沟通，但不要把它当成一项可以依赖的政策来下单。

**不能开小鸡。** 服务条款里对嵌套虚拟化有明确限制：在 KVM VPS 里再跑虚拟机、开 VPS 服务、跑需要硬件虚拟化的模拟器，都需要 RackNerd 书面批准，而且不保证 CPU 虚拟化标志（Intel VT-x / AMD-V）会开放。Docker、Docker Compose、LXC/LXD、Kubernetes、K3s 这类容器化负载不受此限制。想做二级分销或者跑嵌套 VM，这批套餐不合适。

**默认不含托管备份。** 除非单独购买备份服务，VPS 不带备份，官方也不对数据完整性负责；重要数据要自己往外部同步。

**不支持降级，也不能直接换机房。** 升级可以开工单，按比例补差价，重装一次生效；降级没有这个选项。机房选错了只能新开一台再迁移数据，所以下单时那一步别随手点。

**这批特价里没有 Windows。** RackNerd 的 Windows VPS 是单独产品线，不在这五款年付套餐里。
